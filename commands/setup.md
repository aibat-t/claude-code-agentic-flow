Изучи текущий проект (только чтение) и запиши в `CLAUDE.md` в корне раздел `## java-flow`.

1. Определи: Maven/Gradle, wrapper, модули, версии Java и Spring Boot, где миграции (Flyway/Liquibase), тестовый стек.
2. Проверь команды на деле: `-q` компиляция одного модуля должна проходить.
3. Выбери 3–5 эталонных классов из реального кода: сервис, контроллер, unit-тест (+ консьюмер или репозиторий, если есть).
4. Запиши раздел (не больше ~40 строк):

```
## java-flow
- Сборка: <Maven|Gradle>, Java <v>, Spring Boot <v>
- Полный билд: `<cmd>`
- Билд модуля: `<cmd>`
- Один тест: `<cmd>`
- Модули: `<module>` — <назначение>; ...
- Миграции: `<path>`, именование `<pattern>`
- Тесты: <JUnit 5, Mockito, AssertJ, ...>; unit — `<path>`, интеграционные — `<path/суффикс>`
- Эталоны:
  - сервис — `<path>`
  - контроллер — `<path>`
  - unit-тест — `<path>`
- Планы: `docs/plans/` (не коммитить)
```

Правила:
- Если `CLAUDE.md` нет — создай. Если есть — не удаляй и не переписывай существующий текст; раздел `## java-flow` добавь в конец или обнови только его.
- Только факты из кода, каждый путь существует. Неизвестное — пометь `TODO`.
- В конце покажи добавленный раздел и вопросы по `TODO`.
