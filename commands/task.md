Задача: $ARGUMENTS

1. **План** — skill `planning`. Вопросы до плана и апрув плана — **единственные остановки**: жди ответа пользователя.
2. После апрува — **реализация** как в `/ccaf:implement` для этого плана (код → тесты → `verifier`, до 3 попыток).
3. `verifier` PASS → **отправка** — skill `shipping`.
4. После 3 неудачных попыток или расхождения плана с кодом — стоп и отчёт, не shipping.

Итог: план, ветка, коммит, результат проверки.
